# commit-and-mr обновляет заголовок существующего PR

`commit-and-mr --existing-mr` принимает `--mr-title`: заголовок открытого PR заменяется через `gh pr edit --title`, статус Draft не трогается; префикс `Draft: ` добавляется только если PR действительно draft, без удвоения и без учёта регистра (`Draft:`, `draft:`, `DRAFT:`), а у не-draft PR заголовок ставится как задан. Без файла описания тело PR не меняется (spec-блок отдельно не отправляется). С `--description-only` флаг можно использовать без файла описания — тогда обновляется только заголовок. Без `--mr-title` заголовок существующего PR остаётся прежним. Обновление — `./ops upgrade` и `./ops sync`.
